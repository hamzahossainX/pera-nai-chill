## 1. Summary of Changes

### A. RunRules Data & V3 Forward-Compatibility (`src/config/rules.ts` [NEW])
- Defined typed `RunRules` interface:
  ```ts
  export interface RunRules {
    mode: "stage" | "timeAttack" | "hunt";
    timeLimitSec: number | null;
    lives: number;
    winCondition: "catch_villain" | "survive_timer" | "custom";
  }
  ```
- Declared `DEFAULT_STAGE_RULES` with `mode: "stage"` and `timeLimitSec: null`, directly fulfilling the V3 forward-compat constraint (`docs/ROADMAP.md` & `docs/spec/MULTIPLAYER_V3.md §8`).
- Defined `STAGE_CONFIG`: 1000m target distance to safe house, speed-to-meters ratio, and combo target of 10 for the 3rd star.
- Implemented `calculateStars()` evaluating 1–3 star rules per PLAN §2.6:
  - ★ 1 star: Caught the villain (`villainHp === 0`).
  - ★ 2 stars: Patience > 50% remaining at end.
  - ★ 3 stars: Best combo achieved >= 10.

### B. Distance Bar & Stage Progress (`src/store/useGameStore.ts`, `src/game/scenes/RunScene.ts`, `src/components/game/HudOverlay.tsx`)
- Added `distanceMeters`, `stageProgress` (0..100%), `bestCombo`, and `starsResult` to `useGameStore`.
- `RunScene.ts`: Advances distance dynamically in `update` loop using effective runner speed and delta.
- Safehouse Escape: If `distanceMeters >= 1000` before the villain's HP is depleted, the villain reaches the safehouse, triggering `failReason: "escaped"` and ending the run.
- `HudOverlay.tsx`: Displays top-center Distance Progress Bar (`🏃 দূরত্ব: XXm` / `🏠 আস্তানা: 1000m`) with animated progress bar indicator.

### C. Result Screen Skeleton (`src/components/gameover/GameOverScreen.tsx`)
- On victory, renders 3 animated stars (★ ★ ★) with gold/glow for earned stars and muted gray for unearned stars.
- Displays detailed breakdown checklist for each star requirement (Chor Caught, Patience > 50%, 10x Combo).
- Adds "পরবর্তী স্টেজ / NEXT STAGE →" CTA button advancing sequentially through Dhaka map progression (`mirpur` → `farmgate` → `newmarket`).

### D. Persistence v1 with Schema Migration (`src/services/storage.ts` [NEW])
- Implemented `SaveDataV1` schema versioning under `pernaichill_save_v1`.
- Built automatic migration scanning legacy unversioned keys (`dhaka_runner_shop_unlocked`, `dhaka_runner_equipped_outfit`, `dhaka_runner_achievements`, `dhaka_runner_claimed_achievements`), converting them to versioned v1 save format.
- Implemented `recordMapStars(mapId, stars)` recording highest stars per map and unlocking subsequent maps upon scoring at least 1 star.
- All storage accesses strictly wrapped in `try/catch` to guarantee zero crashes under private/sandboxed browsing (satisfying pattern P10).

### E. Daily Reward Outlier Fixed (Audit G-08) (`src/config/dailyChallenge.ts`)
- Fixed daily challenge reward outlier from 5000 Taka to 150 Taka, balancing the reward economy where runs award ~50-100 Taka and shop cosmetics cost ~200-500 Taka.
