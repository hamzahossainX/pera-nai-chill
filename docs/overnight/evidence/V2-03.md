## Changes
1. **`ControlSource` Abstraction:**
   - `src/game/input/ControlSource.ts` [NEW]:
     - Defines `InputCommandType` (`LANE_UP`, `LANE_DOWN`, `JUMP`, `DASH`, `ATTACK`, `ULTIMATE`, `TAUNT`).
     - Defines `InputCommand` (`{ type, weaponId?, timestamp? }`) and `ControlSource` interface (`onCommand`, `destroy`).
   - `src/game/input/KeyboardTouchSource.ts` [NEW]:
     - Listens to keyboard (`ArrowUp`/`KeyW`, `ArrowDown`/`KeyS`, `Space`, `Shift`, `Digit1-4`, `KeyE`, `KeyT`).
     - Captures canvas touch gestures (vertical swipes for lane change, horizontal swipe for dash, tap right half for jump).
     - Listens to `"input:command"` events over `gameBus`.
   - `src/game/input/BotSource.ts` [NEW]:
     - Programmatic control source supporting `emit()`, `queueCommand()`, and `update(deltaMs)`. Used by unit tests and unblocks V2-40a bot harness.

2. **Chaser Movement State Machine:**
   - `src/game/entities/Chaser.ts`:
     - Added `setLane(lane)`, `laneUp()`, and `laneDown()`: clamped strictly to `[0, 2]`, smoothly moving through `rig.motion.setLaneY(targetY)` with 140ms scale tween.
     - Added `jump()`: 520ms airtime arc via `rig.motion.jump(60, 520)`, prevents double-jumping while in mid-air (`isJumping` guard).
     - Added `dash()`: costs 25 stamina (`useGameStore`), 2.5s cooldown (`dashCooldownTimer`), applies forward impulse (+90px) to close the gap.
     - Updated `update(time, delta)` to tick cooldown timers.

3. **Decoupled RunScene Loop (Fixes G-02):**
   - `src/game/scenes/RunScene.ts`:
     - Deleted `this.chaser.followLane(this.villain.currentLane);` from `update()` — chaser no longer mirrors AI villain.
     - Connected `ControlSource` (`setControlSource(new KeyboardTouchSource(this))`).
     - Added `handleInputCommand(cmd)` routing commands to chaser movement and combat.
     - Added proper unbind and cleanup on shutdown/destroy.

4. **UI & On-Screen Touch Controls:**
   - `src/components/game/TouchControls.tsx` [NEW]:
     - Left thumb zone: Lane Up (▲) and Lane Down (▼) buttons.
     - Right thumb zone: Jump (ArrowUp) and Dash (Zap) buttons.
     - Mounted in `src/components/shell/AppShell.tsx` when `screen === "PLAYING"`.
   - `src/components/game/WeaponDock.tsx`:
     - Remapped Space key from ultimate to Jump; KeyE triggers ultimate per GAME_PLAN_V2 §2.1.
   - `src/game/bus.ts`:
     - Typed `"input:command": { command: InputCommand }` in `GameEventTypes`.
   - `src/game/testHook.ts`:
     - Registered debug helpers: `command`, `laneUp`, `laneDown`, `jump`, `dash`.
     - Exposed `isJumping` and `isDashing` in `getState().chaser`.
