## Changes
1. **`src/game/motion/EntityMotion.ts` [NEW]:**
   - Single owner of entity positions `(x, y)` channels:
     - `homeX`: base anchor position (e.g. 320 for chaser, 880 for villain)
     - `offsetX`: sub-stepped damped harmonic oscillator (`omega = 18`, `zeta = 0.92`) providing smooth impulse dissipation
     - `laneY`: smooth exponential lerp towards `targetLaneY`
     - `jumpY`: parabolic normalized vertical arc (`4 * h * p * (1 - p)`) for jumps/vaults
     - `extraY`: vertical offset for trips/knockdowns
     - `clamp`: hard bounding box clamping `x ∈ [minX, maxX]` (default `[60, 1220]`)
   - Method `applyTo(target: Positionable)` safely applies computed `(x, y)` to target without ad-hoc writes.

2. **Integration into Entities:**
   - `src/game/entities/CharacterRig.ts`:
     - Added `public motion: EntityMotion` instantiated in constructor.
     - Updated `update(time, delta)` to advance `this.motion.update(delta)` and `this.motion.applyTo(this)`.
     - Replaced direct `x: targetX` tween in `triggerHitStun` with `this.motion.applyImpulse(knockbackX)` (auto-recovers within 400 ms).
     - Replaced direct `x: this.x + 60` tween in `triggerDead` with `this.motion.applyImpulse(60)`.
     - Replaced direct `y: this.y + 20` tween in `triggerTrip` with `this.motion.extraY = 20`.
   - `src/game/entities/Villain.ts`:
     - Replaced `this.rig.y = currentY` snapback in `vault()` with `this.rig.motion.vault(50, 400)` (fixes C-03).
     - Replaced direct `y: targetY` tween in `setLane()` with `this.rig.motion.setLaneY(targetY)`.
   - `src/game/entities/Chaser.ts`:
     - Replaced direct `y: targetY` tween in `followLane()` with `this.rig.motion.setLaneY(targetY)`.
   - `src/game/entities/Obstacle.ts` and `src/game/entities/PickupItem.ts`:
     - Replaced `this.x -= ...` with `this.setX(...)`.
